# LumenBazaar Frontend

The public web application for LumenBazaar sellers, buyers, agents, reviewers, and operators.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- TanStack Query
- Zod
- Stellar Wallets Kit
- Freighter support

## Setup

```bash
pnpm install
pnpm dev
```

## Validation

```bash
pnpm check
```

## Environment

Runtime variables are documented as the app is implemented. Testnet is the default target, and
mainnet-compatible flows remain feature-flagged until the backend and contract acceptance criteria are
met.
