# Support

Use GitHub issues for reproducible frontend defects and scoped feature requests. Include the route,
browser, wallet, network, expected behavior, actual behavior, and safe reproduction steps.

Do not post seed phrases, secret keys, signed payment payloads, private account data, or credentials.
Report vulnerabilities through the private process in `SECURITY.md`.

Maintainers provide best-effort community support. An issue is not a service-level agreement, and
testnet behavior must not be treated as production financial advice or a mainnet guarantee.
